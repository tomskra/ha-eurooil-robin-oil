# EuroOil Home Assistant integration

This custom integration reads public station and fuel-price data from the EuroOil Srdcovka API. It does not require an account or API key.

## Install

Copy the `custom_components/eurooil` directory into your Home Assistant configuration directory so the resulting path is:

```text
<config>/custom_components/eurooil/
```

Restart Home Assistant, then open **Settings → Devices & services → Add integration**, search for **EuroOil**, select a station, and choose the fuel types to monitor. All supported fuel types offered at that station are selected by default. Napajedla is available in the station list.

## Entities

The integration can create price sensors for Diesel, Diesel Plus, Natural 95, BA 98 Super+, BA 91 Special, LPG PB, Optimal BA95, CNG, AdBlue, and HVO (XTL), depending on station availability. Prices are in CZK per litre. Each entity exposes the source update time and price validity timestamps as attributes.

The API is polled every 30 minutes. Existing recorder history can be used with `mini-graph-card`; the integration does not backfill prices from before installation.

## Lovelace example

```yaml
type: custom:mini-graph-card
name: EuroOil ceny nafty (7 dní)
hours_to_show: 168
points_per_hour: 1
entities:
  - entity: sensor.eurooil_napajedla_diesel
    name: Diesel
  - entity: sensor.eurooil_napajedla_diesel_plus
    name: Diesel Plus
```

Entity IDs are generated by Home Assistant from the station and product names and may differ if matching entities already existed.
